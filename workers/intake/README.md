# ECO Studios Intake API\n\nCloudflare Worker that validates and stores public website requests in the EU D1 database.\n\nDeploy from this directory with Wrangler after reviewing the configured account and D1 binding. Set the Worker route/API URL in the website form if the deployment name changes.\n\n## Endpoints\n- `GET /health` health check\n- `POST /api/requests` validated intake\n\n## Secrets and integrations\nEmail and Notion sync are intentionally disabled until verified Resend credentials and a Notion integration token are supplied. File uploads are disabled until R2 is enabled. The current form accepts HTTPS reference links.\n
