# ECO Studios

Sitio independiente de ECO Studios: música, identidad creativa y producción audiovisual.

## Publicación
Este repositorio usa GitHub Actions para publicar el contenido estático de la raíz en GitHub Pages. En Settings → Pages, seleccionar **GitHub Actions** como fuente de publicación.

## Recursos visuales
Las imágenes iniciales se cargan desde el repositorio público existente `eco-music-web`; luego pueden copiarse aquí para que el sitio sea totalmente independiente de esos recursos.
